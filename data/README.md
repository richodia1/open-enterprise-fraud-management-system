# Data Workspace

This folder is for dataset instructions and lightweight metadata only.

Do not commit raw, processed, or external datasets to Git. Use local folders such as:

```text
data/raw/
data/interim/
data/processed/
data/external/
```

Those folders are ignored because public fraud datasets can be large, licensed separately, or unsuitable for redistribution.

See [ML and AI Strategy](../docs/ml-ai-strategy.md) for the first recommended datasets.
